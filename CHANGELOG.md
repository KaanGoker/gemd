# Changelog

## 1.0.0

- Live preview for Obsidian notes: wikilinks, callouts, image embeds, tables and KaTeX math.
- Backlinks panel.
- Obsidian Kanban boards with the plugin's card and list menus, archive, collapse, search, dates, and board, list and table views.
- `Ctrl+L` task toggle, `Ctrl+N` new note, a New tab page, and Go to Folder (`Ctrl+Shift+O`).
- One `gemd.fontSize` setting.
