# Changelog

## 1.0.2

- Edits save on their own, like Obsidian, so a file changed by another program (Syncthing, git, an AI agent) shows up at once.

## 1.0.1

- Gemd starts only in a workspace with an `.obsidian` folder; Markdown files still open in Gemd anywhere.
- The New tab icon is a PNG.
- License notices for the bundled open source packages in `THIRD_PARTY_NOTICES.md`.
- The README starts with the cover image.

## 1.0.0

- Live preview for Obsidian notes: wikilinks, callouts, image embeds, tables and KaTeX math.
- Backlinks panel.
- Obsidian Kanban boards with the plugin's card and list menus, archive, collapse, search, dates, and board, list and table views.
- `Ctrl+L` task toggle, `Ctrl+N` new note, a New tab page, and Go to Folder (`Ctrl+Shift+O`).
- One `gemd.fontSize` setting.
